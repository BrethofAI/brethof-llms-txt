# Examples

Real output of the generator on public projects, kept here so you can see what it writes. These are **our generator's drafts, not files those projects publish**. Each is saved as `.md` so GitHub shows it rendered; an `llms.txt` is plain Markdown either way.

- [linux-kernel.llms.md](linux-kernel.llms.md): the Linux kernel's documentation tree, about a hundred folders, folded to one link per area.
- [pgvector.llms.md](pgvector.llms.md): a project whose docs are its README; the README's own sections are linked.
- [chatglm3-chinese.llms.md](chatglm3-chinese.llms.md): a project whose docs are in Chinese; the file is written in Chinese.

[`llms-txt.yml`](llms-txt.yml) is the workflow to copy for the GitHub Action.
